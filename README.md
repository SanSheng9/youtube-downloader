# YouTube Downloader

Терминальная программа на Go для скачивания видео с YouTube. Спрашивает ссылку
и качество, показывает список реально доступных разрешений и сохраняет готовый
файл в текущую папку.

Внутри exe встроен проверенный движок **yt-dlp** (версия 2026.10.26), поэтому
программа корректно работает с текущими ограничениями YouTube (PO-токены,
раздельные видео- и аудиодорожки, защиты от прямого скачивания).

## Возможности

- Ссылки `youtube.com/watch?v=...`, `youtu.be/...`, `shorts/...` или 11-символьный ID.
- Список доступных разрешений от 144p до 2160p с кодеками и примерным размером.
- Выбор качества в интерактивном меню (Enter — лучшее).
- Скачивание видео и аудио и объединение через `ffmpeg`.
- Прогресс скачивания, скорость и оставшееся время.
- Безопасные имена файлов, защита от перезаписи.
- Отмена по `Ctrl+C` с удалением временных файлов.
- Один exe: yt-dlp распаковывается во временный кэш автоматически.

## Установка готовой сборки

1. Скачайте `YouTubeDownloader.exe` со страницы
   [Releases](https://github.com/SanSheng9/youtube-downloader/releases).
2. Установите `ffmpeg` (см. ниже).
3. Запустите exe из терминала или двойным щелчком.

## Требования

- Windows 10/11 (x64).
- **ffmpeg** — обязателен для объединения видео и звука.
  Без него программа сможет скачать только редкие готовые форматы, где звук
  уже встроен в видеофайл.

### Установка ffmpeg

```powershell
winget install Gyan.FFmpeg
```

После установки перезапустите терминал. Программа ищет `ffmpeg` в `PATH`,
рядом с exe и в текущей папке.

## Запуск

```powershell
.\YouTubeDownloader.exe
```

Или сразу со ссылкой:

```powershell
.\YouTubeDownloader.exe "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
```

Затем выберите номер качества из списка.

Готовый файл сохраняется в папку, из которой запущена программа, с именем вида
`Название видео [1080p].mp4`.

## Обновление yt-dlp

Если YouTube изменит что-то и скачивание перестанет работать, положите свежий
`yt-dlp.exe` рядом с `YouTubeDownloader.exe` — он имеет приоритет над встроенной
копией. Скачать: https://github.com/yt-dlp/yt-dlp/releases

## Сборка из исходников

Для сборки нужен файл `tools/yt-dlp.exe` (он встроится в бинарник):

```powershell
go build -trimpath -ldflags "-s -w" -o YouTubeDownloader.exe .
```

## Структура проекта

- `main.go` — интерфейс, меню качества, вызов yt-dlp, сохранение файла.
- `console_windows.go` — UTF-8 в консоли Windows.
- `console_other.go` — заглушка для других ОС.
- `tools/yt-dlp.exe` — встроенный движок скачивания.
